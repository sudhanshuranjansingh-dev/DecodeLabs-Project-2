# Data Analytics Project 2 – Exploratory Data Analysis (EDA)

# Project Overview

This project is a part of the **DecodeLabs Data Analytics Internship (Batch 2026)**. The objective is to perform **Exploratory Data Analysis (EDA)** on a dataset using **Python** and **Pandas** to understand data patterns, trends, and distributions.

# Objectives

* Load and inspect the dataset.
* Perform descriptive statistical analysis.
* Identify trends and patterns.
* Detect outliers in the dataset.
* Generate meaningful visualizations.
* Summarize key insights from the analysis.

# Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Microsoft Excel
* Visual Studio Code

# Project Files

* **Dataset** – Excel dataset used for analysis.
* **Python Script / Notebook** – Contains all EDA operations.
* **Charts & Graphs** – Visual representations of the analysis.
* **README.md** – Project documentation.
